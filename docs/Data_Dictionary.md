# Data Dictionary

## Project
**Child Fever & Care-Seeking Power BI Dashboard**

## Overview

This document describes the main variables used in the Child Fever & Care-Seeking Power BI Dashboard. The dataset contains information on caregivers, children experiencing fever or acute febrile illness (AFI), healthcare access, knowledge, perceptions, care-seeking behavior, and outcomes.

## Core Variables

| Variable | Description | Type |
|---|---|---|
| Age | Age of the caregiver/respondent | Numeric |
| Gender | Gender of the respondent | Categorical |
| Educational level | Highest educational level attained by the respondent | Categorical |
| Occupation | Occupation of the respondent | Categorical |
| Household Income | Household income category | Categorical |
| Healthcare Autonomy | Respondent's role in healthcare decision-making | Categorical |
| Under-5 Count | Number of children under five in the household | Numeric |
| Household Type | Type of household | Categorical |
| AFI Awareness | Awareness of acute febrile illness | Categorical |
| Fever Definition | Respondent's understanding of fever | Categorical |
| Perceived Seriousness | Perception of fever severity | Categorical |
| Danger Signs | Knowledge/recognition of danger signs | Categorical |
| CareSeeking_Time | Time taken to seek care after fever onset | Categorical |
| First Action | First action taken when the child developed fever | Categorical |
| Facility Visited | Type of healthcare facility visited | Categorical |
| Physical Accessibility | Perceived physical access to healthcare | Categorical |
| Service Affordability | Perceived affordability of healthcare services | Categorical |
| Decision Maker | Person or group making healthcare decisions | Categorical |
| Referral | Whether formal referral occurred | Categorical |
| Hospitalization | Whether the child was hospitalized | Categorical |
| Clinical Outcome | Outcome following care | Categorical |

## Main Analytical Variable

### CareSeeking_Time

- **Within 24 Hours** — timely care-seeking
- **After 24 Hours** — delayed care-seeking

## Analytical Interpretation

The dashboard primarily examines differences in care-seeking timing across caregiver characteristics, healthcare access, knowledge, perceptions, and healthcare pathways.

The analysis is descriptive and identifies patterns in the dataset. It does not establish causal relationships.
