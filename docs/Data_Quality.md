# Data Quality

## Project
**Child Fever & Care-Seeking Power BI Dashboard**

## Dataset Overview

The dataset contains **422 respondents** and includes variables covering caregiver characteristics, child fever-related knowledge and perceptions, healthcare access, care-seeking behavior, and healthcare outcomes.

## Data Quality Checks

The dataset was reviewed before dashboard development to improve consistency and analytical reliability.

### Checks Performed

- Reviewed variable names and structure
- Checked categorical values for consistency
- Reviewed missing or incomplete responses
- Checked numerical variables for inappropriate values
- Reviewed duplicate records where applicable
- Verified categories used in Power BI visuals
- Checked relationships between analytical tables
- Validated calculated measures against the underlying data

## Categorical Data

Categorical variables were reviewed for consistency in spelling, capitalization, category naming, Yes/No responses, care-seeking time categories, healthcare facility categories, and knowledge and perception categories.

## Analytical Validation

Key dashboard totals were checked against the dataset.

### Respondents

**Total respondents: 422**

### Care-Seeking Time

| Category | Respondents | Percentage |
|---|---:|---:|
| After 24 Hours | 268 | 63.5% |
| Within 24 Hours | 154 | 36.5% |
| **Total** | **422** | **100%** |

## Quality Considerations

The dashboard findings should be interpreted as descriptive patterns within the available dataset. Percentages and comparisons represent the respondents included in the dataset and should not automatically be generalized beyond that population.

## Conclusion

The dataset was sufficiently structured and validated for descriptive Power BI analysis of child fever care-seeking behavior.
